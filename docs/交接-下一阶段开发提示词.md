【引擎与平台踩坑清单】（每一条都是真金白银换来的，照做）
═══════════════════════════════════════════
A. 动画：
 - 关键帧可插值属性**只有** opacity / scale / rotate / translateX / translateY / borderRadius / borderWidth / shadow* / 颜色。**没有 scaleX / scaleY / width / height**，传了会当不可插值属性在段中点硬切。
 - **禁止 onComplete 链式循环**：`Widget:BaseUpdate` 完成分支会在回调之后执行 `self.animation_ = nil`，把回调里刚创建的下一个动画立刻清掉（实测只走两拍）。无限循环一律 `loop = true` + `direction = "alternate"`。
 - 一个 widget 只有一个动画槽：同一元素要同时"位移 + 旋转"必须拆成两层父容器分别挂。
 - `rotate` 正角度 = **屏幕顺时针**（nanovg 约定）。
 - opacity 动画的元素起始必须 `opacity = 0`，**不能 `visible = false`**（display:none 下 opacity 动画完全不可见）。
 - 循环动画不会泄漏：换页时 `UI.SetRoot(root, true)` 会 `Destroy()` 旧根并注销动画追踪。
B. 布局（Yoga）：
 - `width="100%"` + `marginHorizontal` 会**横向溢出**（100% 不为 margin 让位）→ 外层用 `paddingHorizontal`，内层 `width="100%"`。
 - 列容器里**定宽子项不会自动居中**，必须给外层满宽容器加 `alignItems="center"`（或给子项包居中容器）。
 - `UI.Label` **不会自动换行**，长文案会被横向裁断 → 用 `W.wrapLines(text, 每行字数)` 手动断行。
 - `UI.Button` 有单行文本 auto-fit 管线：**多行复合按钮必须用 `UI.Panel + onClick`**，否则副标题会溢出按钮。
 - 全画幅叠加层（`position="absolute"` + `width/height="100%"`）必须绝对定位，否则多层 100% 高度会在列容器里纵向叠加（实测 320→960 溢出告警）。
C. 资源与运行时：
 - **禁止用 `fs.exists` 预判打包资源**：设备上 `fileSystem:FileExists` 只看沙箱，打包进 ResourceCache 的 JSON 恒为 false（曾导致"每日挑战点不进去"）。包内资源可读性只能用 `fs.readText` 实测。
 - `os.clock()` 在该平台**不推进**，计时必须用 `eventData["TimeStep"]:GetFloat()` 的 dt；引擎 `SubscribeToEvent("Update")` 是单槽，只有 `scripts/ui/ticker.lua` 订阅，其他一律 `Ticker.add(fn)`。
 - 字体子集必须覆盖 GB2312 全 6763 字 ∪ 题库全字段 ∪ **Lua/config 里全部非 ASCII 字符**（只扫 CJK 会把 ‹ 　「」￥– 漏成豆腐块）。改了任何中文文案后要重跑 `python3 tools/build_verification_font.py --chars 12000` 并把产物覆盖 `assets/Fonts/MiSans-*.ttf` 两份。
