## 一、游戏描述（给 ChatGPT 的背景信息，也可直接用于商店后台）

**游戏名**：成语小状元

**一句话定位**
> 边玩边学的成语填字，从童生考到状元！

**商店简介（143 字，2026-10-25 定稿）**
> 穿越回古代书院，从童生一路考到状元！三百余个关卡、八百余条成语，交叉填字玩法上手即懂：从备选字中挑字填入棋盘，拼出一条条成语。答错不扣资源、提示每日免费，通关还能在图鉴里读释义、记错题。府邸升级、门客挂机、每日挑战、签到任务，休闲又长知识，全家都能玩。

**玩法要点**
- 核心是 N×N 汉字网格：横竖方向各自构成四字成语，成语之间共享交叉字；玩家先解「锚点成语」，再用交叉字反推其余空格。
- 从字库挑字填入棋盘，填对/填错/完成都有即时反馈；答错不扣资源，每日有免费提示。
- 长线成长：官职晋升（童生 → 状元）、府邸扩建、门客挂机、成语图鉴（释义 + 错题本）、每日挑战、签到任务。
- 体量：300 个主线关卡、829 条成语题库、20 张挑战卷；单局 2–3 分钟，竖屏单手操作。

**气质关键词**
清新、书卷气、轻松益智、治愈、东方国风、不说教、不逼氪。

**目标人群**
全年龄泛用户（25–50 岁为主，兼顾中老年与学生家长），通勤、排队、睡前的碎片时间。

**美术调性（从两张实机截图提炼）**
- 背景：薄荷绿 → 浅青/浅天蓝的柔和渐变，点缀竹叶、云纹、细碎光点。
- 面板：米白 / 纯白圆角字块与卡片，浅绿描边 + 柔和投影。
- 主色：翡翠绿 `#3A9E6C`、墨绿文字 `#2D4A3C`；点缀暖金 `#F2A83C` / `#FCC65C`、朱红印章色 `#E46454`（少量）。
- 风格：扁平矢量 + 轻水彩纸纹，圆润干净、留白充足；不是 3D 写实，也没有厚重描边。
- 游戏里还有一位捧书翻页的 Q 版小书童（主页循环动画）。

## 三、提示词（整段复制给 ChatGPT）

```
请为一款手机游戏设计「游戏图标 / App Icon」，输出 1:1 正方形图片，1024×1024 px。
请同时参考我上传的两张游戏实机截图，取它们的配色与质感。

【游戏信息】
游戏名：成语小状元
类型：国风成语填字 / 益智休闲，竖屏单机手游，全年龄
核心玩法：横竖交叉的汉字网格，从备选字里挑字填入棋盘，拼出一条条四字成语；
          从童生一路考到状元，含府邸升级、成语图鉴、每日挑战。
气质：清新、书卷气、轻松益智、治愈、东方国风、不说教、不逼氪。
人群：25–50 岁泛用户为主，兼顾中老年与学生家长；通勤、睡前的碎片时间。

【视觉参考（以我上传的截图为准）】
- 背景：薄荷绿 → 浅青/浅天蓝的柔和渐变，点缀竹叶、云纹、细碎光点。
- 面板：米白 / 纯白圆角字块与卡片，浅绿描边 + 柔和投影。
- 主色：翡翠绿 #3A9E6C、墨绿文字 #2D4A3C；
  点缀：暖金 #F2A83C / #FCC65C、朱红印章色 #E46454（少量）。
- 风格：扁平矢量 + 轻水彩纸纹，圆润、干净、留白充足；不要 3D 写实、不要厚重描边。

【构图要求】
- 主体居中、基本对称，只用「一个」高辨识度核心图形，缩小到 48×48 仍能一眼认出。
- 从这些元素里选 1 个主图形 + 最多 2 个点缀：
  Q 版古代小书童捧书 / 毛笔与展开书卷 / 玉质印章 / 状元帽 / 2×2 汉字字块 / 竹叶。
- 主体收在画面中心约 75–80% 的安全区内，四周留边距
  （商店会把方图自动切成圆角，半径约 114px @512，边角元素会被切掉）。
- 输出直角方图，不要自己加圆角，不要白底 / 黑底 / 透明底。

【文字】
- 首选「无字纯图形版」：图标上不出现任何文字、字母、数字、水印。
- 如果要出带字版，只能出现简体中文「成语小状元」五个字，
  字形必须准确，不能有错字、缺字、乱码或多余文案，并让字形成为画面主体。

【避免】
水印、多余文案、二维码、外加边框、细碎难辨的小元素、过多渐变光效、
写实照片质感、白底/黑底/透明底、自行裁圆角、日式或欧美奇幻风。

请先给出 3 个不同主图形的构思（每个一句话），等我选一个再出图；
出图后请自查：主体是否在安全区内、缩到小尺寸是否仍清晰、有无多余文字或水印。
```

## 四、尺寸：到底要几乘几

**先分清两个不同的字段**（很容易混）：

| 物料 | TapTap 官方规格 | 本项目现状 | 建议 |
|---|---|---|---|
| **游戏图标 icon**（后台必填，日常说的「logo」） | **不低于 512×512 px，1:1 正方形**；PNG/JPG；**直角方图**，请勿自行裁圆角；不得白底/黑底/透明底；平台会自动做半径 114px 的圆角裁剪，主体要留在安全区 | `assets/Textures/icon_game.png` 512×512；10 枚候选 512×512；S27 的 4 张候选 1024×1024 | **让 ChatGPT 出 1024×1024**，挑中后缩到 **512×512** 上传（2 倍冗余，缩小后更清晰） |
| **游戏 LOGO**（另一个独立字段，会叠在宣传图上） | PNG **透明底**；宽 ≥1280 px **或** 高 ≥720 px 满足其一即可，宽高比可自定义；四周不留白；≤4 MB；建议高明度、高识别度 | 尚未制作 | 后期从定稿图标里拆一版透明底字标，不要拿图标直接顶替 |

官方依据：`developer.taptap.cn/docs/store/release/publish/material`（游戏物料要求）、`developer.taptap.io/docs/zh-Hans/store/store-material/`（物料要求）。

**一句话回答**：图标是 **512×512**（1:1，只能更大不能更小），出图按 **1024×1024** 做再缩小上传；如果问的是后台那个独立的「游戏 LOGO」字段，则是 **宽 ≥1280 或高 ≥720 的透明底 PNG**，不是 512 方图。

顺带：截图位要求 ≥3 张 9:16（≥720×1280）**实机截图**，AI 图不能顶替，参考图 1/2 是 864×1920 真机图但不能直接当商店截图用。
