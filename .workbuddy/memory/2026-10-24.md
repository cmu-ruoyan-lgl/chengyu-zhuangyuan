## 17:30 排查「UrhoX Download failed ... .wasm network error」
- 结论：**非游戏代码问题**，是网络层。证据链：
  1) 全项目 grep 无远程 URL、无 DownloadFile/HttpRequest 等网络 API → wasm 由引擎/平台发起；
  2) 该 wasm 17.7MB，实测 CDN 吞吐仅 ~148KB/s（波动到 9.5KB/s），超时窗口内下不完；
  3) 同期 git push 到 maker.taptap.cn:443 也 SSL_ERROR_SYSCALL，属同一网络问题。
- 排查手法：nslookup 看是否被解析到 198.18.x（黑洞 IP）、curl 测速、grep 代码远程依赖。
- 处理：代码侧无需改；本地验证全绿 + 提交推送 + 远端构建成功；弱网下建议换网络重开试玩。
